A few useful details

Know your
workspace.

Which platforms can I use?

Native builds are verified on macOS Apple Silicon, macOS Intel, Windows x64 and Linux x64. Public installers are currently available for macOS through this site and Homebrew. Windows and Linux public installers have not been published yet.

What can I run and edit?

The SQL editor accepts a single SELECT or CTE; MongoDB supports find and read aggregation requests. Arbitrary query results are read-only. The data browser can update supported cells, with primary keys and generated columns protected. Insert/delete rows and schema migrations are not supported in 0.6.0. Database permissions remain the security boundary.

How do SSH tunnels and TLS work?

Tunnels use an installed OpenSSH client, a trusted known_hosts entry, and a key or unlocked SSH agent. Each operation owns its temporary tunnel. Interactive passwords, ProxyJump and MongoDB SRV/replica-set discovery through a single forward are not supported.

Current forwarding changes the driver endpoint to 127.0.0.1. TLS settings are preserved, so a certificate valid only for the original remote hostname fails verification. The app does not silently disable certificate checks.

Where are credentials and history stored?

Connection credentials remain in memory or, when Remember is enabled, the OS credential store. History stores query text locally as plaintext, with a 500-entry global cap. Queries may contain sensitive text; recording can be disabled for the session and history can be cleared. Connection/query tabs are session-only.

Upgrading from the Qt version?

Homebrew now installs the native Rust 0.6.0 app. Existing Qt profiles and keychain entries are preserved, but they are not imported automatically. Recreate your connection profiles in Rust. SQL Server no longer needs Microsoft ODBC Driver.
